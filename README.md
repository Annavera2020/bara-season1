Бара. Курс медитаций — интерактивная книга

Интерактивное веб-приложение по книге «Курс Бары» — 7-дневный медитативный курс про капибару Бара. Каждый день — своя история, практика дня, аудио-гид и вопросы вечера.

Живая версия: https://Annavera2020.github.io/bara-season1/

О проекте

Проект переносит книгу в интерактивный формат: пользователь листает дни, отмечает выполненные практики, слушает аудио-гид и отвечает на вопросы вечера прямо в браузере. Прогресс сохраняется локально (localStorage), так что можно вернуться к курсу в любой момент.

Функциональность





7 дней курса + пролог и эпилог



Прогресс-трекер с отметками пройденных дней



Кнопка «Начать курс» / «Продолжить курс» / «К эпилогу» — подстраивается под прогресс



Аудио-гид на каждый день — плеер с записанным голосом (файлы подключаются отдельно, см. ниже)



Текстовые поля для ответов на вопросы вечера с автосохранением



Журнал ответов за все дни



Адаптивная вёрстка: мобильный вид (карточка) и десктопный вид (двухколоночный)



Поддержка светлой/тёмной темы устройства



Технологии

Один самодостаточный HTML-файл: HTML + CSS + vanilla JavaScript, без сборки и зависимостей. Иллюстрации встроены как base64 — открывается и работает без интернета (кроме шрифтов Google Fonts и аудио). Шрифты — Newsreader, Karla, IBM Plex Mono.

Как добавить аудио-гиды

Плеер каждого дня ищет файл audio/den-<номер>.mp3 (например, audio/den-1.mp3 для дня 1). Положи mp3-файлы с такими именами в папку audio/ рядом с index.html — плеер заработает без правок кода.

Запуск локально

Файл index.html можно открыть прямо в браузере — сервер не требуется.
